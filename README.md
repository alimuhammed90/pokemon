# pokemon

Bu projede logic.py ve main.py dosyaları bulunmaktadır. Bu dosyalardaki kodlarda pokemonu canlandırırız ve ona discord da yönetebileceğimiz kendi pokemonumu oluşturabileceğimiz komut sunarız. Pokemonu seçtikten sonra nadirliğinide öğrenebilirsiniz. Bunları geçtikten sonra pokemonunuzu belli süreler aracılığıyla besleyip büyütebilirsiniz. Genel olarak projemin tanımı bu şekildedir.
